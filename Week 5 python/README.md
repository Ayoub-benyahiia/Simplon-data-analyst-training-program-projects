📊 Netflix Data Analysis Project
📌 Project Context

I worked as a Data Analyst for a streaming platform.
The goal of this project is to analyze the Netflix catalog in order to understand:

Content trends and performance

Distribution between Movies and TV Shows

Genres and production countries

Age classifications (ratings)

Evolution of the catalog over time

This project covers the full data analysis process:
Exploration → Cleaning → Preparation → Visualization → Insights → Dashboard

🎯 Project Objectives

Explore and analyze the Netflix dataset using Python & Pandas

Create clear visualizations with Matplotlib & Seaborn

Answer key business questions about the catalog

Identify important trends and insights

Prepare the dataset for an interactive Power BI dashboard

🗂️ Project Steps
1️⃣ Data Exploration (EDA)

Goal: Understand the dataset before cleaning.

Main actions:

Check dataset structure (info(), describe())

Identify missing values (director, country, rating…)

Analyze distributions (Movies vs TV Shows, genres, countries)

Detect duplicates and anomalies

Create initial visualizations (histograms, countplots, boxplots)

2️⃣ Data Cleaning & Preparation

Goal: Prepare clean data for analysis and dashboard creation.

Main actions:

Handle missing values (remove or replace with "Unknown")

Remove duplicates

Transform multi-value columns (country, listed_in)

Create new columns:

Year added

Month added

Day added

Duration in minutes

Standardize formats (dates, duration, content type)

3️⃣ Data Visualization & Business Analysis

Goal: Answer business questions and identify trends.

Key analyses:

Distribution of content by age rating

Movies vs TV Shows proportion

Content added per year

Evolution of Movies vs TV Shows over time

Number of series between 2011–2021

Productions by country

Productions by country and rating

Genre analysis

Most frequent content categories

Visualization types used:

Bar charts

Pie charts

Line charts

Count plots

Heatmaps

All charts are clearly labeled with titles and legends.

4️⃣ Business Insights

Key insights identified:

Top genres in the catalog

Leading production countries

Growth of Netflix content over time

Evolution of Movies vs TV Shows

Dominant age classifications

A clear summary was prepared for management with actionable insights.

5️⃣ Power BI Dashboard

Goal: Build an interactive dashboard for decision-making.

Steps:

Import cleaned dataset (.csv)

Apply transformations in Power Query (if needed)

Create interactive filters:

Content type

Country

Genre

Year added

Highlight key KPIs and trends
