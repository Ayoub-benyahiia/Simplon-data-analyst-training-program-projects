📊 HR Analytics: Workforce & Retention Dashboard
A comprehensive Power BI project designed to help companies monitor workforce trends, optimize talent management, and analyze turnover through data-driven insights.

🎯 Project Objective
To transform raw HR datasets (Employment history, Salaries, Demographics) into an interactive, professional dashboard that tracks Headcount, Retention, and Turnover with a high-end user experience.

🚀 Key Features
Star Schema Modeling: Optimized data structure with a central Fact table and 8+ Dimensions.

Advanced DAX: Custom metrics for Headcount, Turnover %, and Retention rates.

Interactive UI/UX: * Landing Page: Centralized navigation with hover effects.

Hidden Slicer Panel: A "hamburger" menu for a clean, professional layout.

Dynamic Tooltips: Instant insights into top/bottom salaries on hover.

🛠️ Project Phases
Data Prep: Cleaning People Data and Employment History via Power Query.

Modeling: Building a Star Schema (Fact: People Fact; Dimensions: Dept, Job Level, Demographics, etc.).

Analytics: Creating a dedicated _Measures table for all business logic.

Visualization: Designing 3 main reporting pages:

Headcount: Demographics, Geography, and Departmental breakdowns.

Retention: Slope charts and field parameters for trend analysis.

Turnover: Deep dive into termination types and reasons over time.

🎨 Design System
Palette: Professional Orange & White theme.

Typography: Clean, corporate fonts (DIN/Segoe UI).

Navigation: Synced slicers and bookmark-based navigation for seamless flow.

📂 Repository Structure
Data/: Source CSV files (People Data, Employment History).

Dashboard/: The .pbix Power BI file.

Documentation/: Project brief and data dictionary.
