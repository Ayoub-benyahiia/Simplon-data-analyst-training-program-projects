📊 Sales Dashboard Project
📌 Project Overview

This project aims to transform raw Excel sales files into a clean, structured, and interactive dashboard.

The goal is to analyze sales performance and track key business indicators such as revenue, products, delivery performance, and customer satisfaction.

🎯 Objectives

Clean and prepare sales data

Combine multiple Excel files using Power Query

Create Pivot Tables (TCD)

Build interactive charts

Add dynamic filters (Year, Product, Region, Traffic Source)

Create a professional dashboard

🛠 Tools Used

Microsoft Excel

Power Query

Pivot Tables

Charts & Slicers

📊 Key Indicators

Revenue evolution

Sales by product

Sales by region

Number of sales

Average basket

Delivery rate

Return rate

Customer satisfaction

Traffic source performance

🔄 Features

Cleaned and consolidated data

Interactive filters

Automatic update when new data is added

Clear and professional dashboard layout

⏳ Duration

5 working days
